# Результаты проверки

Проверки выполнены локально в браузере с Supabase в качестве источника данных, под постановщиком и двумя исполнителями. SQL-миграции и настройки Supabase применялись отдельно через панель проекта. Этот отчёт не является полным аудитом безопасности.

## Сборка

- `npm run typecheck` — успешно.
- `npm run build` — успешно.
- Страницы разделены на отдельные файлы сборки через динамические импорты. После этого остаётся предупреждение Vite об одном общем JS-файле библиотек размером около 617 kB. Оно не блокирует сборку; дальнейшее уменьшение общих зависимостей не выполнялось.

## Маршрутизация и общие значения

После выделения маршрутов и enum повторно пройдены TypeScript и production-сборка. Сборка создаёт отдельные файлы LoginPage, ObjectsPage, ObjectPage, TaskPage и MyTasksPage. В браузере проверены список объектов, список задач, ссылки на карточки и обратная навигация, открытие формы новой задачи без сохранения, отображение принятого статуса и история. Неизвестный адрес показывает недоступность. В production-preview защищённый адрес без сессии перенаправляет на лениво загружаемую страницу входа. Ошибок браузерной консоли при проверке не обнаружено. Демонстрационные данные не изменялись.

## Интерфейс и жизненный цикл

- Создание объекта и задачи, выбор исполнителя, проверка обязательного названия.
- Полный цикл: создание → работа → проверка → доработка → работа → повторная проверка → приёмка. Сохраняются участники, время и комментарии всех семи записей истории.
- Пустой и пробельный комментарии доработки отклоняются формой.
- Редактирование содержания и переназначение сохраняют статус, автора, дату создания и историю.
- После приёмки дальнейшие действия по смене статуса не отображаются. Все пять попыток изменить или повторить accepted через API отклонены без изменения истории.
- Возвращение фокуса и повторный рендер не перезагружают данные. Ручное обновление работает; запоздавший ответ не перезаписывает свежий результат.
- Карточка объекта проверена на ширинах 320 и 390 px: длинные названия переносятся, кнопки доступны, горизонтального переполнения не обнаружено.

## Доступ и прямые запросы к API

- Без пользовательской сессии чтение всех четырёх таблиц и вызов RPC создания объекта отклонены.
- Исполнитель видит только свой профиль и назначенные ему задачи, включая общий объект с задачами другого исполнителя.
- Чужая задача, её история и имена участников недоступны по известному UUID.
- После переназначения прежний исполнитель теряет доступ по старой прямой ссылке, новый получает задачу с существующей историей.
- Исполнителю запрещены создание объекта, приёмка задачи и оба RPC удаления. Постановщику запрещены переходы исполнителя.
- Назначение постановщика исполнителем отклоняется.
- Проверенные прямые записи в объекты, профили, метаданные задач и историю отклонены привилегиями. Отдельно проверены INSERT, UPDATE и DELETE истории. Для запросов, способных удалить или изменить данные, использовались несуществующие ID, пустые payload либо прежние значения полей; ожидалась именно ошибка доступа.

## Конкурентные изменения

- Устаревшее редактирование возвращает HTTP 409 / PT409.
- Два одновременных редактирования с одной версией дают один успех и один конфликт.
- Два одновременных перехода revision → in_progress с одной версией дают один успех и один конфликт. История увеличивается ровно на одну запись с правильным участником.

## Безвозвратное удаление

- После подтверждения удалена принятая задача с семью записями истории. Задача и её история исчезли из чтения постановщика; остальные задачи сохранились.
- Проверены предупреждение о последствиях и отмена удаления объекта.
- После подтверждения удалён объект с двумя оставшимися задачами. Итоговые запросы постановщика вернули отсутствие объекта, ноль тестовых задач и ноль записей истории по их ID. Контрольный объект сохранился.
- Защита истории не блокирует каскад задачи и вложенный каскад объекта. Старые URL удалённых записей показывают недоступность.
- Данные и временные страницы, созданные для проверки, удалены. Отдельный контрольный объект сохранён.
